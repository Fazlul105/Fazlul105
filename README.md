## About Me

I am a Computer Science graduate from **BRAC University, Bangladesh** (September 2026).

My primary interests are **full-stack web development, backend engineering, applied AI, and Retrieval-Augmented Generation (RAG) systems**. I focus on building scalable applications across the full development lifecycle—from REST API design and database modeling to automated testing (Jest, Vitest, Supertest) and Docker-based deployment.

My recent work includes **CodeSense AI** (an AI-powered GitHub pull request analysis and code review platform using Next.js, FastAPI, Express.js, and Gemini RAG), **BRACU Bazaar** (a full-stack MERN student marketplace), and an undergraduate machine learning thesis on **apartment price prediction across 29 zones in Dhaka**.

---

## Featured Projects

* **[CodeSense AI](https://github.com/Fazlul105)** — Full-stack GitHub PR review platform featuring AST-based static analysis, ML defect-risk estimation, MongoDB Atlas vector search, and Gemini-powered RAG workflows (`Next.js`, `TypeScript`, `Express.js`, `FastAPI`, `Python`, `Docker`).
* **[BRACU Bazaar](https://github.com/Fazlul105)** — Student marketplace for BRAC University with JWT authentication, role-based access, product search/filtering, cart workflows, and order tracking (`React.js`, `Node.js`, `Express.js`, `MongoDB`, `Tailwind CSS`).
* **Dhaka Apartment Price Prediction (Thesis)** — Evaluated Ridge Regression, Random Forest, and Histogram Gradient Boosting across 8,923 listings in 29 Dhaka zones using bootstrap confidence intervals and conformal prediction.
